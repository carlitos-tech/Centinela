# Guion inicial de demo — Centinela

Borrador preliminar. Se refinará conforme se implemente el MVP.

## Contexto de apertura

Presentar NovaCasa S.A.S. como pyme ficticia y el problema que Centinela resuelve: atención al cliente ágil vía Chat Web asistida por agentes de IA.

## Flujo previsto

1. Mostrar la arquitectura multiagente (`Proyecto → Agentes → Plugins → Skills → Artifacts`) de forma visual.
2. Abrir el canal Chat Web y realizar una consulta típica de un cliente ficticio de NovaCasa S.A.S.
3. Mostrar cómo el agente correspondiente resuelve la consulta usando plugins/skills.
4. Mostrar trazabilidad: issue → PR → evidencia → reporte de fase.
5. Cierre: resumen de gobierno, seguridad y control de costos aplicado durante el desarrollo.

## Pendiente

Este guion depende de funcionalidad aún no implementada (fases posteriores a la 01). Se completará cuando el MVP del canal Chat Web esté disponible.
